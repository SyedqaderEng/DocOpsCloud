## SDKs

### JavaScript/TypeScript
```typescript
import { DocOpsCloud } from '@docopscloud/sdk';

const client = new DocOpsCloud({ apiKey: 'xxx' });

// Convert PDF to Word
const result = await client.convert.pdfToWord({
  file: buffer,
  options: { preserveFormatting: true }
});

// AI Extract
const data = await client.ai.extractInvoice({
  file: buffer,
  fields: ['vendor', 'total', 'date', 'lineItems']
});
```

### Python
```python
from docopscloud import Client

client = Client(api_key="xxx")

# Merge PDFs
```
